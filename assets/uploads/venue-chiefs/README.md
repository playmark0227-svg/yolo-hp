## お願い
- LINEから保存した写真をそのままアップでOK（ファイル名はそのままで大丈夫です）
- どの写真がどの会場か分かるように、可能ならファイル名に会場名を入れてください
  例: `tomakomai.jpg` / `otaru-1.jpg` / `otaru-2.jpg` / `hakodate.jpg` / `asahikawa.jpg`
- 分からなくても、いただいたスクショと照合してこちらで会場に振り分けます

アップロード後、制作側（Claude）が最適化して各会場の説明に配置します。
