# 素材アップロード用フォルダ

クライアントから受領した素材（役員写真・サービス画像・ロゴ など）を
**すべてこのフォルダにアップロード**してください。ファイル名はそのままでOKです。

アップロード後、制作側（Claude）が中身を確認し、
適切な場所（役員紹介・サービスカード・ヘッダーロゴ・favicon など）へ
リサイズ・最適化したうえで配置します。

## アップロード方法（GitHub Web）
1. このフォルダの画面右上「Add file ▸ Upload files」
2. 画像をまとめてドラッグ&ドロップ
3. 下部の「Commit changes」で確定

対応形式の目安: JPG / PNG / WebP / SVG（ロゴ）/ HEIC も可（後でこちらで変換します）
